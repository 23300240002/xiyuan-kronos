## 一句话结论

在模型实际输入是有损量化摘要 Ỹ 时，**支撑内**确定性特征（技术指标）对目标的信息增量被量化损失上界约束、且随量化器趋于无损而必趋于 0；**支撑外**特征（微观结构）的增量与比特预算无关——无损量化器下仍可有 1 bit。

## 解决的具体问题

C-T12-001 §3.1 推翻的断言是「技术指标对模型实际输入 Ỹ 的条件互信息 = 0」。该断言错在把条件集写成了完整 OHLCV 历史 Y。本卡给出修正后的严格陈述：条件集为 Ỹ 时增量**可以**为正，但被量化损失上界约束；并给出支撑外特征的独立机制（构造），从而把 Y3 的「筛特征判据」从一句被推翻的断言恢复为两个可分别检验的机制。

## 符号及定义

| 符号 | 定义 |
|---|---|
| `Y` | 预测时点可用的完整 OHLCV 历史（随机变量，可高维） |
| `Q` | 量化器/摘要映射；`Ỹ = Q(Y)`（例：Kronos 512 根 × 20 bit） |
| `x` | 预测目标（t+1 收益等）。**生成机制任意**，本卡不对 x 作假设 |
| `X_T = g(Y)` | 技术指标：Y 的确定性函数（MACD/RSI 等由 OHLCV 算出） |
| `X_M` | 微观结构特征：一般**不由 Y 决定**（支撑外） |
| `I(·;·|·)` | 互信息，总体层面（可取 ∞；下文不等式在有限时取有限值） |

## 假设

本卡**不引入**新的经济/数据假设。命题 1–3 仅使用：
- (M1) `X_T = g(Y)` 为确定性函数（定义性）；
- (M2) `Ỹ = Q(Y)` 为 Y 的可测函数（定义性）。
x 与 (Y, X_M) 的联合分布任意。无平稳性、无高斯性、无独立假设。

## 严格命题

**命题 1（确定性特征上界）。** 设 X_T = g(Y)，Ỹ = Q(Y)。则
$$I(x; g(Y) \mid \tilde Y) \le I(x; Y \mid \tilde Y) \le H(Y \mid \tilde Y).$$

**证明。** g(Y) 是 Y 的可测函数，故给定 Y 时 g(Y) 无剩余随机性，马尔可夫链
x → (Y, Ỹ) → g(Y) 成立。由条件数据处理不等式，
I(x; g(Y) | Ỹ) ≤ I(x; (Y, Ỹ) | Ỹ) = I(x; Y | Ỹ)
（末等式：Ỹ 关于 Y 可测，条件于 Ỹ 后 (Y,Ỹ) 相对 Ỹ 的增量信息就是 Y）。第二不等式是互信息关于条件集的单调整理（0 ≤ I(x;Y|Ỹ) ≤ H(Y|Ỹ)）。∎

**推论 1（无损输入特例）。** 若 Ỹ = Y（模型输入已含完整历史），则 I(x; g(Y) | Ỹ) = 0。
**证明。** H(g(Y)|Y) = 0。∎
（这正是 C-T12-001 §3.1 原断言在其**本应成立的**条件集下的版本。）

**推论 2（随保真度衰减）。** 设量化器族 {Q_k} 满足 H(Y | Q_k(Y)) → 0（k→∞，渐近无损）。则对任意 g，I(x; g(Y) | Q_k(Y)) → 0。
**证明。** 命题 1 + 夹逼。∎

**命题 2（支撑外构造）。** 存在联合分布、Y 不决定的 X_M、目标 x 与量化器 Q，使得 Ỹ = Q(Y) = Y（无损，I(x;Y|Ỹ) = 0）而 I(x; X_M | Ỹ) = 1 (bit)。
**证明（构造）。** Y, X_M ~ Bern(1/2) 独立；x = Y ⊕ X_M；Q 为恒等。则 I(x; Y | Ỹ) = I(x; Y | Y) = 0；给定 Ỹ = Y，x 与 X_M = x ⊕ Y 一一对应，故 I(x; X_M | Ỹ) = 1。∎

**命题 3（两项分解）。** 设复合特征 X = (X_T, X_M)，X_T = g(Y)。则
$$I(x; X \mid \tilde Y) = \underbrace{I(x; X_T \mid \tilde Y)}_{\le\, I(x; Y \mid \tilde Y)} + I(x; X_M \mid \tilde Y, X_T) \le I(x; Y \mid \tilde Y) + I(x; X_M \mid \tilde Y).$$

**证明。** 链式法则 + 命题 1 + 条件集单调性（I(x;X_M|Ỹ,X_T) ≤ I(x;X_M|Ỹ)）。∎
第一项即 C-T12-001 §3.1 所称「量化丢失的补偿」，第二项是「支撑外真新息」的条件版。

## 反例与失效边界

- **上界是上界，不是估计**：命题 1 不给实际增量大小；增量可为 0（g 常数，或 g 在 Ỹ 下冗余）。
- **命题 2 是存在性，不是必然性**：不证明微观结构在本市场 DGP 下**有**增量；实际大小是经验问题。C-T12-001 原句「微观结构一定有增量」降级为「可以有增量（构造），大小待测」。
- **条件依赖输入**：若模型输入除 Ỹ 外还有原始 OHLCV 无损通道，技术指标增量恰为 0（推论 1）。本卡结论以「Ỹ 是该信息的唯一模型输入」为条件。
- **总体量**：全部 MI 为总体互信息；有限样本估计上界 I(x;Y|Ỹ) 需要额外假设/代理（如「从码重建长窗口统计量的误差」），本卡不展开。
- **渐近无损是条件**：推论 2 要求量化器族满足 H(Y|Q_k(Y)) → 0；对 Kronos 固定 20-bit 码本，「更高保真」需另构造（如 40-bit 重量化或精确输入 oracle），是否满足本条件需对具体 tokenizer 验证（见下一步）。

## 可使用性：对应设计或决策

1. **特征筛选实验改为保真度梯度设计**（Y3′ 主检验）：同一历史在 20-bit / 40-bit / 精确输入三种模型输入下分别测两类特征的边际增量。
   - 预测 P1：技术指标增量沿梯度单调向 0 收缩；若不收缩（或超出上界的估计误差带），「量化丢失补偿」机制被否证。
   - 预测 P2：微观结构增量沿梯度不衰减；若按支撑内方式衰减，其「支撑外」归类被否证。
   - 原容量斜率检验降为次级检验（它不直接区分两个机制）。
2. **无损输入情形有精确零增量预言**：若模型输入已含精确 OHLCV，技术指标的期望信息增量恰为 0——任何观测到的正增益只能归因于容量/优化效应，不是信息效应。这是无需估计上界即可使用的判定。
3. **上界的可操作代理**：I(x;Y|Ỹ) 本身不可直接估；代理量 = 从 Ỹ（码）重建长窗口统计量（MACD 等）的误差。代理与上界的关系（何时构成有效上界）本卡不主张，需另行推导。

## 可解释性：机制与直觉

- 技术指标是 OHLCV 的确定性函数：它「知道」的都被 Y 知道。模型若已看到完整的 Y，技术指标无话可说（增量 = 0）。模型只看到有损摘要 Ỹ 时，技术指标相当于「替模型回忆」被量化丢掉的信息——但它最多只能补回量化丢掉的那么多（上界），且量化越无损可补越少（→0）。
- 微观结构数据（订单流等）不在 OHLCV 的支撑上：它携带的信息与量化 Ỹ 丢了什么无关。量化器做到无损也只能无损 Y，补不出支撑外的东西——所以这类特征的增量不随比特预算衰减（构造：无损下仍 1 bit）。
- 两类特征的「有用性」来源不同、方向相反（一个随保真度衰减、一个与保真度无关），因此不能用同一套对照实验检验——这正是 C-T12-001 §3.1「两个不同强度、方向不同的机制，不能合并」的严格化。

## 可讲述性：60 秒说明

「特征有没有用，取决于模型实际看到了什么。技术指标是 OHLCV 的确定性函数：模型输入是 20-bit 有损摘要时，它能补量化丢掉的信息，但补的上界就是量化损失本身，量化越接近无损它越没用；输入已是精确 OHLCV 时，它的信息增量精确为零。微观结构数据在 OHLCV 支撑之外，量化器做到无损它也能带来 1 bit 的目标信息，收益与比特预算无关。所以筛特征要分两条线：支撑内特征用『保真度梯度』检验，支撑外特征用『消融对照』检验。」

## 不允许据此声称什么

- ❌ 「技术指标没有价值」——上界可为正，20-bit 情形增量可能非零；
- ❌ 「微观结构一定在本项目数据上有增量」——命题 2 只是存在性构造；
- ❌ 任何量化损失的具体 bit 数——本卡未估计 I(x;Y|Ỹ) 或 H(Y|Ỹ) 在项目 tokenizer 上的值；
- ❌ 「首次提出/文献中不存在」——未检索；
- ❌ 有限样本增量估计的有效性——总体层面的结果；
- ❌ 对 20→40-bit 重量化可行的任何断言——取决于 Kronos tokenizer 实现，未读代码，未验证。
