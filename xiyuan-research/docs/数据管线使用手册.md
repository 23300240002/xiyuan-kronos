> v1.0 手册与其描述的旧管线（download_binance_* / extract_features / align_data / run_pipeline）已整体退役，已归档（个人仓库历史分支内保留原件）。**旧管线输出不得作为任何训练输入**（前视与语义问题记录于 `research/claims/C-CODE-HF-001.md`）。

## 现行管道 = `scripts/hf_data_pipeline.py` v2

```
原始导出（vendor parquet/CSV）
  ├─ 盘口:   clean_orderbook(assume_tz=…, max_gap=…) ─→ add_event_ofi ─→ aggregate_orderbook(window, min_snapshots=4, rv_grid="5s")
  ├─ 逐笔:   clean_trades(side_col=…, side_semantics=…, assume_tz=…) ─→ aggregate_trades(window)
  └─ K线:    normalise_kline(assume_tz=…, timestamp_semantics=…, bar_frequency=…)   ← 时间戳语义必须显式声明
特征×K线:    align_features_to_kline(kline, features)        # 有界陈旧度，输出 feature_age_ms / hf_available
标签:        make_future_labels(kline, horizon=…)            # RV 口径 + 时间网格连续性校验（label_ok_contiguity）
```

**必填语义参数（never-guess 原则）**：

| 参数 | 取值 | 备注 |
|---|---|---|
| `assume_tz` | 全管道必填 | Binance=UTC；Tushare naive=Asia/Shanghai |
| `timestamp_semantics` | `bar_end`（Tushare stk_mins，左开右闭）/ `bar_start`（Binance open_time） | 集合竞价在 Tushare 单独占 09:30 bar（deep_F §3） |
| `side_semantics` | `aggressor` / `maker`（Binance `m`=buyer-is-maker 用这个）/ `absent` | 错传=整列符号翻转，故必填 |
| `horizon` | 正整数（bar 数） | 无默认值 |

**语义要点**：右闭右标全 bin 网格（空格子保留行、特征 NaN，绝不 0 填充）；OFI=CKS 2014 事件级 $e_n$ 全窗求和（不可测=NaN）；mid_return=bar 到 bar 链式；RV 走 5s previous-tick 子网格（等间隔标准，deep_A §1.5）；对齐陈旧上限默认 2×中位特征间隔。
