# 07 · L2 订单簿三臂消融（短上下文，真正的 L2 预测头）

> 2026-10-25 · 数据：18 天 L2 十档（分散在 2024–2026），8,694 票中取与 K 线同票池的 500 只
> 设定：L=24 根（2 小时）/ H=12 根（1 小时）/ stride=1 / 按 L2 日期切分 12 训练 + 3 验证 + 3 测试
> 代码：`xy/data/l2_tensor.py`（3 秒快照 → 5min 桶聚合，7 维）+ `xy/train/run_l2arm.py`

## 1. 为什么需要这个实验

M2 十八天分析（`04_M2多日截面.md`）发现：**imb1 的增量 IC = +0.0593（t=2.73）跨 18 天稳定为正**，
而三臂主实验（`06_三臂消融.md`）用 M1 成交流特征做的融合臂没有增量。
两条通道测的是不同东西——成交流是"实际发生了什么"，订单簿是"盘口挂着什么"。
本实验把**真正的 L2 十档特征**接进同一个三臂架构，直接检验 P2。

## 2. 主结果（测试段，3 种子）

| 臂 | 输入 | pooled IC 均值 ± std | pooled RankIC 均值 ± std | 逐种子 IC |
|---|---|---|---|---|
| arm-1 | 仅 K 线 | +0.00328 ± 0.00964 | **+0.05983 ± 0.01138** | −0.0085 / +0.0033 / +0.0151 |
| **arm-2** | **仅 L2 订单簿（7 维）** | **+0.02676 ± 0.01149** | +0.03228 ± 0.02982 | **+0.0430 / +0.0176 / +0.0197（全正）** |
| arm-3 | 融合 | −0.01612 ± 0.01556 | +0.01729 ± 0.03832 | +0.0004 / −0.0369 / −0.0119 |

配对差（同种子）：
```
ΔIC(arm-3 − arm-1) = −0.01940   逐种子：+0.0089 / −0.0402 / −0.0270  → 2/3 为负
ΔIC(arm-3 − arm-2) = −0.04288   逐种子：−0.0426 / −0.0545 / −0.0316  → 3/3 为负
```

## 3. 三个结论

### ① L2 订单簿单独就有预测力——这是本项目最干净的正面结果

arm-2 只用 7 维订单簿状态（imb1/imb5/imb10/ofi/slope5/spread/dmid），
**不给任何 K 线**，测试段 IC 均值 **+0.0268**，是 arm-1（仅 K 线，+0.0033）的 **8 倍**，
且 3 个种子全部为正。这与 M2 的特征级发现（imb1 增量 IC +0.0593，t=2.73）
互相印证：**盘口状态携带 K 线之外的真实信息**。

### ② 融合臂比两个单模态都差——当前 Fusion 架构失败

arm-3 的 IC（−0.0161）不仅低于 arm-2（+0.0268），还低于 arm-1（+0.0033），
且逐种子对两个单模态臂的差**全为负**。方差不降反升（±0.0156 vs arm-1 的 ±0.0096）。

这不是"增量不存在"，而是**当前融合方式有害**。最可能的原因：
- 交叉注意力在 L=24 的短序列上噪声占比过高（注意力只有 24 个 key 可选）；
- 门控初值 0 + LayerNorm 残差在仅 12 天训练数据下训练不稳；
- 两路特征的尺度/噪声特性差异大（订单簿特征是 O(0.1) 的状态量，K 线隐状态是 O(1) 的表示）。

### ③ K 线的排序能力远强于幅度能力

arm-1 的 RankIC（+0.0598）是其 IC（+0.0033）的 18 倍。MSE 训练被少数大涨跌主导，
模型学到了排序但学不对幅度——这正是 Rank 损失（Q1，正在跑）要解决的问题。

## 4. 与主三臂实验（M1）的对照

| | M1 成交流（672 天） | L2 订单簿（18 天） |
|---|---|---|
| arm-1 测试段 IC | +0.0379（L=240） | +0.0033（L=24） |
| arm-2 测试段 IC | +0.0008（CI 跨 0） | **+0.0268（3 种子全正）** |
| arm-3 vs arm-1 | −0.0015（t=−0.64，不可区分） | −0.0194（显著更差） |

**同一种架构，换输入通道结论完全反转**：M1 通道的微观分支无信号，
L2 通道的微观分支有强信号。P2 命题（微观结构增量）在 L2 通道上**部分成立**——
增量存在于订单簿状态，不存在于成交流水；但当前的融合实现会把增量破坏掉。

## 5. 下一步（按优先级）

1. **修融合**：换更稳的融合方式（门控残差 / 特征拼接 + 小 MLP / 或干脆两路分别预测后集成），
   目标是在 arm-2 的 +0.0268 之上拿到正增量。
2. **扩 L2 天数**：18 天（且分散）是本实验的最大限制。网盘还有 2.85TB/676 天可用，
   若下 100+ 天，lookback 可提高到 48–96，结论会强得多。
3. **Rank 损失**：arm-1 的 RankIC/IC = 18 倍说明排序损失可能同时改善所有臂。

## 6. 引用纪律

- 禁止写"融合提升预测"（arm-3 比两个单模态都差）。
- 禁止写"微观结构无用"（arm-2 有 3 种子全正的 +0.0268）。
- 允许写：L2 订单簿单独可预测 1 小时收益（IC +0.027，3 种子一致）；
  当前交叉注意力融合架构在该设定下有害；M1 与 L2 是两个信息量不同的通道。
- 必须同时说明：测试段只有 3 天，IC 绝对值小，结论强度受天数限制。

## 7. 融合方式对比（2026-10-26 01:00）

针对 §3② 的发现（交叉注意力融合有害），实现了两种替代融合并各跑 3 种子：

| 融合方式 | 机制 | 测试段 IC | 测试段 RankIC | 参数量 |
|---|---|---|---|---|
| **xattn**（原版） | K线 query × 微观 key/value 交叉注意力 + σ门控残差 | **−0.0161 ± 0.0156** | +0.0173 | 1.88M |
| **concat**（新） | K线末点 ⊕ 微观序列均值 → 拼接 → Head | **+0.0022 ± 0.0065** | **+0.0452** | 0.53M |
| **gate_res**（新） | h + tanh(g)·W(m_mean)，无注意力 | −0.0129 ± 0.0022 (n=2) | +0.0332 | 0.56M |

参照：arm-1（仅K线）IC +0.0033 / RankIC +0.0598；arm-2（仅L2）IC +0.0268 / RankIC +0.0323。

### 结论

**concat 把融合从"有害"修到了"中性"，但没有产生增量。**

- IC 从 −0.0161 提升到 +0.0022（+0.018 的改善），方差从 ±0.0156 降到 ±0.0065（降 58%）
- RankIC 从 +0.0173 提升到 +0.0452（翻 2.6 倍）
- 但 concat 的 IC（+0.0022）仍**低于 arm-2 的 +0.0268**，RankIC（+0.0452）仍**低于 arm-1 的 +0.0598**
- gate_res 介于两者之间，IC 仍为负

**诊断**：问题不在"融合模块实现"（concat 证明可以实现得不破坏），而在
**18 天分散数据 + 短上下文（L=24）不足以让模型学到两路的互补关系**。
两路各自单独用都比融合好，说明当前的样本量下"合并"这个动作本身就是亏的。

### 对下一步的含义

1. 融合要成立，**必须先扩数据**（L2 天数 → 100+，lookback 才能提到 48–96）
2. 在数据扩充前，**最优配置是 arm-2（仅 L2）单独用**，IC +0.0268 是当前最好的单一模型
3. 若一定要融合，用 **concat**（最稳、方差最小、参数量只有 1/3.5）
