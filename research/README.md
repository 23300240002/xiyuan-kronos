# research/ — 曦源课题实验代码

本目录是**课题自研的实验管线**，与上游 Kronos 官方代码（`model/`、`finetune/`、
`examples/`）相互独立：官方代码原样保留，我们的代码全部放在 `v1/` 下。

## v1/ 是什么

在冻结的 Kronos 主干外接"微观结构分支"，做三臂消融，目标是在 A 股上复现并检验
论文量级的截面 IC 结果。

| 目录 | 内容 |
|---|---|
| `v1/xy/` | 全部代码：数据构建（`xy/data/`）、模型（`xy/model/`）、训练（`xy/train/`）、评估（`xy/eval/`） |
| `v1/reports/` | 6 份报告：数据卡、M2 单日/多日截面、交叉对比、基线对比、三臂消融 |
| `v1/results/` | 全部实验的 `result.json` / `test_v1.json`（每个结论可回溯到具体文件） |
| `v1/HANDOFF.md` | **新人入口**：环境、命令序列、已知坑、纪律 |
| `v1/README.md` | 模块清单与快速开始 |

## 三句话结论（详见 reports/06_三臂消融.md）

1. **arm-1（冻结 Kronos + 正则化头）有强且可泛化的信号**：测试段 3 种子
   pooled IC 全部显著为正（+0.028 ~ +0.046，CI 均不跨 0）。
2. **arm-2（仅微观结构）在测试段无信号**（CI 跨 0）——微观特征单独不构成预测器。
3. **arm-3（融合）与 arm-1 统计上不可区分**：配对 ΔIC = −0.0015（t = −0.64），
   P2 命题（微观结构增量）**未被支持**，但排除了三种替代解释。
